# Regras — SRD 5.2

O **System Reference Document 5.2** é o conjunto de regras básicas do D&D 5e (versão 2024),
publicado pela Wizards of the Coast sob licença aberta **Creative Commons CC-BY-4.0**.

## Como obter
1. Baixe o PDF do SRD 5.2 na página oficial de SRD da D&D Beyond / Wizards of the Coast
   (pesquise "D&D SRD 5.2").
2. Salve aqui nesta pasta (PDFs estão no `.gitignore` para não pesar o repositório).
3. Suba o PDF como arquivo de conhecimento no Projeto "Mestre RPG D&D".

## Regras da casa
Anote abaixo qualquer regra opcional ou ajuste combinado — e suba este arquivo também.

- (exemplo) Poção de cura como ação bônus.
- (exemplo) Acerto crítico: dano máximo do dado + rolagem normal.
