# Regras — SRD 5.2

O **System Reference Document 5.2** é o conjunto de regras básicas do D&D 5e (versão 2024),
publicado pela Wizards of the Coast sob licença aberta **Creative Commons CC-BY-4.0**.

## Como obter
1. Baixe o PDF do SRD 5.2 na página oficial de SRD da D&D Beyond / Wizards of the Coast
   (pesquise "D&D SRD 5.2").
2. Salve aqui nesta pasta (PDFs estão no `.gitignore` para não pesar o repositório).
3. Suba o PDF como arquivo de conhecimento no Projeto "Mestre RPG D&D", junto com `glossario-2024.md`.

## Livro do Jogador 2024 (só na máquina)
`dampd-5e---livro-do-jogador-2024.pdf` é a tradução da comunidade (Heróis Anônimos) do Livro do Jogador
de 2024. Serve só de **referência de termos em português**: o app e o glossário seguem os nomes dele
(Guardião, Pequenino, 1º círculo, Ordeiro...). Não vai para o git nem para o Projeto (36 MB, conteúdo
fora do SRD). O conteúdo de regras continua vindo só do SRD 5.2.

`glossario-2024.md` é gerado por `npm run glossario` a partir de `app/js/dados.js` (não edite à mão).
O `D&D5E_LIVRO_DO_JOGADOR.pdf` (2014) não é mais usado e pode ser apagado.
